# 配债观察标的与预期总收益

Status: ready-for-agent

本规格与 `trading-toolkit-web/.scratch/placement-observation-total-return/spec.md` 配套。Service 负责可验证的观察范围、过期状态和历史价格输入；Web 负责基于本地假设的展示与派生计算。

## Problem Statement

当前待配售列表在股权登记日结束后移除标的，使用户无法持续观察已进入末段审批、登记、申购或待上市阶段的可转债。详情中的 `record_price` 是当前价格近似值，不能支持历史盈亏判断；同时，预计上市收益率属于 Web 本地设置，服务端不应伪造或保存该假设。

## Solution

服务将“当前可参与的配债候选标的”和“配债观察标的”分开。尚未上市、已达到 `上市委通过`、`同意注册` 或后续登记、申购、待上市阶段的记录持续进入观察响应；登记日已过的记录明确标记为已过期。

对可识别股权登记日的观察标的，服务提供一手配债所需的实际整百股数、登记日收盘价、其后首个 A 股交易日及该日收盘价。缺失任一历史价格时，服务明确返回不可用原因，绝不以当前价、自然日或推断值替代。

## User Stories

1. 作为配债观察者，我希望看到已到达上市委通过或同意注册阶段的未上市标的，以便跟踪近期可能配售的项目。
2. 作为配债观察者，我希望登记日临近的标的排在最前，以便优先处理时间敏感事项。
3. 作为配债观察者，我希望登记日未知的标的仍被保留，以便在公告补齐后继续跟踪。
4. 作为配债观察者，我希望登记日已过的标的仍可见且被标记为已过期，以便复盘而不误认为仍可参与。
5. 作为配债观察者，我希望最近过期的标的先于更早过期的标的显示，以便优先查看刚结束的机会。
6. 作为配债观察者，我希望已上市的转债不再作为配债观察标的，以避免把已结束的发行周期混入列表。
7. 作为配债观察者，我希望观察记录保留其审批阶段和登记日，以便理解为何被纳入列表。
8. 作为配债观察者，我希望服务区分当前可参与、登记日未知和登记日已过，以便客户端不需要猜测资格。
9. 作为详情用户，我希望获得股权登记日收盘价和后续首个交易日收盘价，以便审阅预期总收益的历史输入。
10. 作为详情用户，我希望遇到周末或交易所休市时使用后续首个交易日，而不是自然日次日，以避免错误盈亏。
11. 作为详情用户，我希望历史价格缺失时看到不可用状态和原因，以便不把当前行情误认为历史结果。
12. 作为使用本地收益率假设的用户，我希望服务不读取、保存或回传我的个人假设，以便保持客户端设置边界。
13. 作为数据维护者，我希望观察范围和价格输入保留来源与新鲜度，以便在上游异常时判断数据可信度。
14. 作为接口消费者，我希望原有待配售字段保持兼容，以便现有页面和导出不被破坏。

## Implementation Decisions

- 服务响应新增观察语义，而不改变“配债候选标的”仍表示登记日未结束、可能参与的既有定义。
- 观察范围限于未上市且已进入 `上市委通过`、`同意注册`、登记、申购或待上市阶段的记录；早期审批阶段和已上市记录不在范围内。
- 服务提供明确的观察状态：当前可参与、登记日未知、已过期。状态依据股权登记日和中国 A 股交易日期计算，不由客户端从显示文本推断。
- 服务提供稳定的排序输入，使客户端可将未来或当日登记、登记日未知、已过期三类记录分别排序；同组内使用日期保证确定性。
- 历史价格输入采用正股日线：登记日收盘价与其后首个有有效收盘价的 A 股交易日收盘价。服务同时返回实际使用的交易日期。
- 一手配债所需股数必须按既有配售额度计算，并向上取整到 A 股 100 股交易单位。
- 历史输入以可用性状态和原因表达缺失、上游失败或无交易日，不得返回近似当前价、零值或伪造日期。
- 预计上市溢价率不进入服务端 API 的持久化状态；服务只返回客户端计算税费前预期总收益所需的事实输入。
- 观察数据继续遵循既有快照、来源追溯和新鲜度契约；过期观察不等同于当前可执行资格。

## Testing Decisions

- 最高服务端测试边界为待配售 HTTP 响应，而不是单独验证私有筛选或缓存实现。
- 响应测试覆盖末段审批纳入、早期阶段排除、已上市排除、登记日未知、登记日当天、未来登记日与已过期状态。
- 服务测试覆盖按日期分组的稳定排序输入，以及周末、节假日后的首个交易日价格选择。
- 服务测试覆盖登记日或后续交易日收盘价缺失时返回不可用状态，且不会回退到当前价。
- 复用现有待配售可见性、快照刷新和交易日价格相关测试的 fixture 与 HTTP seam；新增断言只验证对消费者可见的状态和字段。
- Web 侧以 Pinia 待配售派生列表和详情展示为最高客户端 seam，验证状态标签、三组排序、全局收益率切换后的总收益重算与不可用显示。
- 浏览器回归覆盖桌面与移动端的配债列表和详情，确认过期标记、公式说明和长文本不重叠或裁切。

## Out of Scope

- 实际获配数量、用户账户持仓、券商佣金、印花税、融资利息和个人成交回执。
- 转债上市后的已实现收益、实际卖出价格和税后收益追踪。
- 将预期收益率从 Web 本地设置迁移到服务端、数据库或用户账户。
- 扩展到尚未进入末段审批的早期可转债项目。
- 对缺失历史数据进行模型估值、当前价替代或收益推断。

## Further Notes

详情页展示的税费前预期总收益以一手配债为单位：实际整百股数乘以“后续首个交易日收盘价减登记日收盘价”，加上 `1,000 元 × 当前全局预期上市溢价率`。它必须带有假设披露，不能描述为已实现收益或保证收益。

对应领域决策见 `docs/adr/0005-placement-observation-and-expected-total-return.md`。
