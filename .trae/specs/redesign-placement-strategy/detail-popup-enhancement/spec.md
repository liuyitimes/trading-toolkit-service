# 详情弹窗增加发行时间轴与板块标签 Spec

## Why

用户审查配售详情弹窗后，发现两个对决策有帮助的信息缺失：

1. **发行时间轴**：当前详情弹窗只在"发行信息"区展示方案进展文本（如"同意注册"），缺乏可视化进度视图。投资者需要一眼看清当前标的处于发行流程的哪个阶段、前面还有几步、距离上市还有多远——类似 GitLab Pipeline 的 stage 视图。
2. **是否热门板块**：投资者选股时很在意正股是否属于当前市场热门板块（AI、新能源、医药等），当前没有任何板块信息。

已有数据支撑：
- 后端 `_get_bond_status_by_progress` 已定义 7 个有序阶段的映射：董事会预案 → 股东大会批准 → 交易所受理 → 上市委通过 → 同意注册 → 申购中 → 待上市
- 前端从后端收到 `status` 字段，可直接映射到 7 个阶段中的位置
- 板块/行业信息集思录 pre_list 接口未直接返回，但可通过正股名称关键词做简单分类

## What Changes

### 前端 `index.js` — `formatPendingItem` 的 detail 对象
- **NEW** 新增 `stageList` 字段（7 阶段数组，含 `currentIndex` 标记），传给详情弹窗
- **NEW** 新增 `sectorTag` / `isHotSector` 字段，基于正股名称关键词判断是否属于热门板块
- 不改后端、不改 mock 数据

### 前端 `index.wxml` — 详情弹窗
- **MODIFIED** 在弹窗顶部（溢价率滑块之后、核心指标之前）插入"发行时间轴"区
  - 用 step 组件（圆点+连线）展示 7 个阶段
  - 已完成阶段用绿色 / 当前阶段用金色高亮+箭头 / 待完成灰色
  - 每个阶段显示中文名称
- **NEW** 在弹窗顶部（溢价率滑块之前或之后）插入"板块标签"区
  - 显示正股所属板块标签（如"新能源"）
  - 热门板块带🔥标记和"热门"角标
  - 未识别到板块则显示"--"

### `index.wxss`
- **NEW** 发行时间轴样式：step 圆点 + 连线 + 阶段名称
- **NEW** 板块标签样式

### 板块分类方案（前端关键词匹配，不改后端）
维护一个 `SECTOR_KEYWORDS` 常量映射，匹配正股名称关键字到行业标签：
```
AI/人工智能： 智能、科技、信息、数据、软件、AI、数字
新能源：      新能源、光伏、风电、电池、锂电
半导体/芯片： 半导、芯片、微电、电子
医药生物：    医药、生物、医疗、药
消费：        消费、食品、饮料、家电
金融：        银行、证券、保险、金融
汽车/新能源车：汽车、车、电动
低空经济：    低空、无人机、航空
机械/制造：   机械、装备、制造、精密
化工/材料：   化工、材料、化学、化纤
```

热门板块判定：上述列表中当前市场公认的热门赛道为 AI/人工智能、新能源、半导体/芯片、医药生物、低空经济 → 标记 `isHotSector = true`

## Impact
- Affected code: `miniprogram/pages/convertible/index.js`、`index.wxml`、`index.wxss`
- 不改后端、不改 mock 数据
- 不改变列表项显示，仅影响详情弹窗

## ADDED Requirements

### Requirement: 发行时间轴
详情弹窗 SHALL 在弹出后立即显示一条水平或垂直的 7 阶段发行时间轴，包含从"董事会预案"到"待上市"的完整流程，用颜色区分完成/当前/待完成。

#### Scenario: 申购中的标的
- **WHEN** `status='申购中'`
- **THEN** 时间轴显示前 5 阶段（董事会→股东大会→交易所受理→上市委通过→同意注册）为绿色已完成，第 6 阶段（申购中）为金色当前，第 7 阶段（待上市）为灰色待完成

#### Scenario: 董事会预案早期阶段
- **WHEN** `status='董事会预案'`
- **THEN** 时间轴显示第 1 阶段为金色当前，其余 6 阶段为灰色待完成

### Requirement: 板块标签
详情弹窗 SHALL 根据正股名称关键字匹配显示行业板块标签，热门板块附加🔥标记。

#### Scenario: 中科曙光
- **WHEN** `stockName='中科曙光'`
- **THEN** 匹配"科技"→板块标签"科技"，热门板块含🔥

#### Scenario: 迪威尔
- **WHEN** `stockName='迪威尔'`
- **THEN** 无法匹配已知关键词→显示"--"

## REMOVED Requirements
无
