# 套利策略的可执行性校验

状态：研究结论（2026-07-12）

本文定义可转债原股东优先配售、封闭式基金折价和港股 IPO 页面进入“可执行”列表前必须具备的基金/发行级事实。行情、历史收益、PE 差和折价仅可作为观察指标；缺少下列可追溯证据时不得以“套利机会”或预期收益排序。

## 共通规则

每条可执行记录必须有：发行人或管理人公告 URL、公告日期/抓取时间、事实有效期、冲突处理结果。字段缺失、日期过期、行情时间与参考值不可比，或只来自聚合站点时，状态必须是“观察”。

## 可转债原股东优先配售

中国证监会规定，可转债**可以**全部或部分向原股东优先配售，比例应在发行公告中披露；网上投资者申购时无需缴付申购资金，但获配后必须按时足额缴款。优先配售并非所有发行的自动权利。[《证券发行与承销管理办法》第十九条、相关缴款规则](https://www.csrc.gov.cn/csrc/c106256/c1654028/content.shtml)

可执行前必须核验并展示：

| 事实 | 最低字段 | 不能推断的原因 |
| --- | --- | --- |
| 优配资格 | 是否优配、股权登记日、正股代码、登记日收市资格 | 交易日持仓或“待发”状态不能证明登记在册。 |
| 配售能力 | 每股配售面额/比例、配售代码、可配面额、最小申购单位 | `发行规模`、正股市值或“百元含权”不能替代公告配售比例。 |
| 时间与资金 | 缴款/申购截止、付款要求、发行公告 URL 与日期 | “无需预缴”不代表不需缴款；逾期或弃配后不可执行。 |
| 后续路径 | 上市日、转股起始日及各自公告 | 可转债发行结束后六个月方可转股，不能展示为即时转股套利。[科创板再融资办法第六十二条](https://www.csrc.gov.cn/csrc/c106256/c1654016/content.shtml) |

当前风险：`convertible_bond.py` 和 `Convertible.vue` 的 `per_share_allocation`、`cash_ratio`、固定 20% `expected_profit` 适合比较持仓占用，不能单独证明优配资格或形成可执行收益。固定首日涨幅假设必须显式标为用户假设，不能进入默认排序。

## 封闭式基金折价

封闭期内基金份额固定，基金份额持有人不得申请赎回；因此“实时价格低于净值”不构成可按净值即时退出的套利。[《证券投资基金法》第四十五条](https://www.csrc.gov.cn/csrc/c101939/c1045353/content.shtml)

封闭式基金净值至少每周披露一次，不能将最近披露净值与实时场内价格描述为同一时点的可执行价差。[《公开募集证券投资基金信息披露管理办法》第十九条](https://www.csrc.gov.cn/csrc/c106256/c1653985/1653985/files/166-8%E3%80%8A%E5%85%AC%E5%BC%80%E5%8B%9F%E9%9B%86%E8%AF%81%E5%88%B8%E6%8A%95%E8%B5%84%E5%9F%BA%E9%87%91%E4%BF%A1%E6%81%AF%E6%8A%AB%E9%9C%B2%E7%AE%A1%E7%90%86%E5%8A%9E%E6%B3%95%E3%80%8B.pdf)

可执行前必须有逐基金、未过期的收敛事件：到期/清盘、转为开放式、要约或其他合同载明的退出机制；并展示合同终止或开放日、现金支付或可赎回规则、公告 URL/日期及净值日期。否则只显示“观察：折价”，不计算“年化折价收益”。

当前风险：`closed_end.py` 的 `maturity_date` 始终为空，而客户端在 `closedEnd.js` 依据它计算 `annualizedDiscount`；这会将不存在的到期/退出路径和延迟净值折价混为套利回报。列表还应分别显示场内报价时间、净值日期和事件证据状态。

## 港股 IPO 公开发售

港股公开发售的申请与配发并非等价：FINI 的结算和配发结果在后续流程形成，申请金额不是已建仓金额，也不能预先当作可卖数量。[HKEX FINI Information Pack（2025 年 4 月）](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Next-Generation-Post-Trade-Programme/Fini/FINI-Information-Pack-EN-April-2025.pdf)

HKEX 的 “How to Apply” 模板明确，申请可经券商/托管人向 HKSCC EIPO 提交，具体程序和条款取决于发行文件与申购渠道；配发结果亦由发行文件安排。[HKEX “How to Apply” 模板](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Next-Generation-Post-Trade-Programme/Fini/How-to-apply-section-template-EN.docx) 同一受益人重复申请受限，不能用多账户放大可申购金额。[CCASS Guide](https://www.hkex.com.hk/-/media/hkex-market/services/settlement-and-depository/overview/admission-of-securities-into-ccass/ccass-guide)

可执行前必须核验并展示：

| 阶段 | 必需事实 |
| --- | --- |
| 可申购 | 招股书/公告链接、公开发售开始和渠道截止、发行价或价格区间、每手股数、账户渠道已开放、港币余额/融资条件、受益人唯一性检查。 |
| 已申请 | 申请渠道、申请手数、冻结金额和结果公布日期。 |
| 已获配 | 官方配发结果、实际获配手数、实际成本与退款。 |
| 可交易 | 上市日期、可交易数量；基石/Pre-IPO 等锁定股份必须与公开发售隔离。 |

当前风险：`hk_ipo.py` 抓取的是同花顺聚合表，字段 `apply_limit`、`top_value`、A 股式“申购代码/顶格市值”及 `pe_diff` 不能证明港股账户资格、HKSCC 申请渠道、每手成本或获配概率。前端 `oneHandCost = ipo_price * apply_limit * 10000` 把“申购上限”当作每手数量，口径错误；在取得招股书与券商渠道数据前只能作为观察清单，不能按“低估/收益”排序。

## 建议状态机

所有三类策略统一使用：`观察` -> `可执行` -> `已提交/持有` -> `已确认退出条件`。每次状态跃迁要求对应的带日期来源；缺证据或过期即回退至 `观察`。这与 LOF 页现有的“可追溯来源 + 时效 + 人工核验”原则一致，但各策略的资格和退出字段必须独立维护，不能由交易所、代码或历史行情推断。
