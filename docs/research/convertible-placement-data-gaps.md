# 可转债配债数据缺口记录

## 记录日期

2026-08-08

## 已确认缺口

东方财富待发转债列表不能稳定提供原股东优先配售金额或比例。巨潮官方公告通常要到发行结果或优先配售结果发布后才披露该合计，因此公告发布前无法可靠计算首日可交易量。

## 当前处理

- 配债快照后台按正股代码定向检索巨潮公告并解析 PDF。
- 公告解析成功后，使用原股东优先配售合计覆盖 `shareholder_amount`、`shareholder_ratio` 和 `tradable_amount`。
- 公告未发布、没有匹配公告、表格缺少合计金额或只有无法与金额核对的比例时，相关字段返回 `null`，`placement_data_status=unavailable`，并记录原因。
- HTTP 读取不等待公告下载，避免把慢数据源带入首屏。

## 后续讨论入口

1. 是否能获得交易所或登记结算层面的首日实际可交易量，作为公告金额之外的交叉核验来源。
2. 公告中的大股东锁定、限售或网下份额是否需要单独建模。当前业务口径明确不拆分股东身份，也不凭身份推断锁定。
3. 巨潮公告延迟、PDF 解析失败和公告标题变化的监控与人工复核策略。
