# 回测引擎

状态：当前实现

回测包位于 `backtest/`，以分钟 K 线驱动策略执行。该包是独立 Python 项目，开发依赖通过 `backtest/pyproject.toml` 管理。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `data.py` | 加载并缓存分钟 K 线和前收价 |
| `session.py` | 识别集合竞价、连续竞价和午间休市等交易阶段 |
| `strategy.py` | 定义 `Strategy` 生命周期和下单接口 |
| `broker.py` | 校验手数、价格限制、资金和持仓 |
| `exchange.py` | 维护订单簿并撮合订单 |
| `portfolio.py` | 维护资金、持仓、成交记录和净值曲线 |
| `engine.py` | 按交易日和时间顺序编排回测 |
| `metrics.py` | 生成收益、回撤等绩效指标 |

## 已实现交易规则

- 交易日跳过周末；交易时间区分 09:15-09:25 开盘集合竞价、09:30-11:30 与 13:00-14:57 连续竞价、14:57-15:00 收盘集合竞价。
- 委托数量必须为 100 股整数倍。
- 限价单按主板 10%、科创板和创业板 20%、ST 5% 的涨跌停范围校验。
- 买入资金校验包含佣金和过户费；卖出还包含印花税。
- 当日新买入持仓不可卖出，执行 T+1 限制。
- 每五分钟记录一次权益快照，日终完成集合竞价撮合并清理未成交订单。

## 使用与验证

```powershell
cd backtest
python -m pytest
python examples/mock_demo.py
```

数据加载器当前按需导入 `akshare` 获取分钟 K 线；没有安装该依赖时，可使用 `MockMarketData` 及测试夹具验证策略和撮合规则。

## 扩展边界

策略只应在 `on_bar()` 中生成 `Order`，不要在策略中直接修改资金或持仓。新增交易规则时，优先在 `broker.py`、`exchange.py` 或 `session.py` 实现，并补充 `backtest/tests/` 中的独立测试。
