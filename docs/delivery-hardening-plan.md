# Demo 交付加固计划

状态：已实施；外部平台配置与生产验收待完成。本文记录 Flask 服务在 Demo 阶段的交付约束、最小工程门禁和实施顺序。

## 已确认的范围

- 不实现用户登录、用户鉴权或会话体系。
- 中国大陆访问为尽力而为，不办理 ICP，不承诺大陆节点、低延迟或 SLA。
- Vue Web 使用 Cloudflare Pages；Flask 服务使用 Render 新加坡，并直接提供 HTTP API。
- 供应商推荐优先评估中国互联网公司及其中国可用产品；受限或不适用时再选择海外产品，并明确限制条件。
- 开发使用 SQLite；生产使用可用的免费托管 PostgreSQL。数据库不可用时不发布或回退到上一版，绝不静默使用容器 SQLite。
- 持久化数据可重建。破坏性迁移前手动导出；不建设定时备份、异地复制和灾备。

区域与大陆访问限制的依据见 [中国大陆部署与访问约束](research/china-mainland-hosting-options.md)。

## 实施顺序

### 1. 生产运行边界

- 新增公开且无敏感信息的 `/healthz`。
- 生产环境默认禁用数据源切换、缓存清除和接口日志管理；本地仅在 `ENABLE_ADMIN_API=1` 时开放。
- 将 CORS 改为由环境变量配置的 Cloudflare Pages 正式域名与本地开发地址，不允许凭据。
- 请求日志不再保存请求或响应正文，只保留必要的结构化元数据。

验证：生产配置下管理端点不可用；`/healthz` 返回 200 且不泄露数据库、缓存或数据源信息；允许与拒绝的 Origin 都有自动化覆盖。

### 2. 数据库演进

- 为 SQLAlchemy 模型引入 Alembic，并以首个基线迁移替代生产中的 `create_all`。
- 本地测试继续使用 SQLite；生产必须设置非 SQLite 的 `DATABASE_URL`。
- 在部署前运行迁移；迁移失败中止发布并保留上一版本。
- 为破坏性迁移提供手动导出命令和恢复验证说明。

验证：空库可迁移到最新版本；已有库升级后通过服务测试；生产环境缺少 PostgreSQL 配置时启动失败。

### 3. 端点契约

- 在本仓库新增机器可读的 HTTP 端点矩阵，记录稳定路径、方法、可见性和成功响应信封。
- 服务测试从 Flask `url_map` 校验清单中的端点真实存在，并验证统一成功/失败响应。
- 清理 `favorites/toggle` 契约缺口，选定并实现或移除其中一种接口表达。
- 跨仓库 API 改动遵循“先新增兼容服务端能力，再切换 Web，最后删除旧能力”。

验证：缺失路径、错误方法或不符合信封的响应都会使 Service CI 失败。

### 4. CI、发布与治理

- 将后端测试与部署改为同一条 `test -> deploy -> smoke` 链路；部署只在受保护 `main` 合并后执行。
- 部署到 Render 新加坡，设置 `DATABASE_URL`、允许的 CORS Origin、Sentry DSN 与生产开关；不使用容器 SQLite。
- GitHub 中为 `main` 配置必需检查和 PR 审查。服务与 Web 的必需检查分别见各自计划。
- 开启 Dependabot 每周创建升级 PR 和 CodeQL 的 `main` / PR 扫描，不自动合并。

验证：失败测试不触发部署；成功部署后 `/healthz` 冒烟检查通过；依赖与代码扫描结果在 PR 中可见。

### 5. 最小可观测性

- 接入 Sentry 免费层的 Flask 异常上报。
- 使用一个免费外部探测器每五分钟请求 `/healthz`，仅在失败时通知。
- 保留 Render 平台日志，按请求 ID、路径、状态码、耗时和错误类型排障。

验证：受控异常能在 Sentry 出现；探测器能发现非 200 状态；日志不包含请求或响应正文。

## 非目标

- 不建设登录、鉴权、RBAC、审计平台、Prometheus、集中式日志集群、自动备份或灾备。
- 不迁移 Flask 到 Cloudflare Worker，不建设 Cloudflare API 代理。
- 不承诺中国大陆网络性能或长期数据恢复。
