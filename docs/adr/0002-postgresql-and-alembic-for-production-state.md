# 生产状态使用 PostgreSQL 与 Alembic

状态：已接受。开发环境继续默认使用 SQLite，以保持本地启动零配置；Render 部署必须使用托管 PostgreSQL，禁止将容器本地文件系统作为持久化存储。数据库结构变更通过 Alembic 迁移执行，而不再依赖应用启动时的 `create_all`。

该选择让配债快照、观察记录和后续用户数据可跨实例和发布保留，并使结构演进可审查、可回滚。SQLite 仍只用于开发和测试。Demo 阶段优先选择可用的免费 PostgreSQL；提供方由 `DATABASE_URL` 配置替换，不为同区部署引入付费要求。

Demo 持久化数据按“可重建”处理：市场数据、快照和观察记录可重新采集。破坏性迁移前手动导出数据库；不建设定时备份、异地复制或灾备，也不承诺恢复历史用户状态。
