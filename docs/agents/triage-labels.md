# 分诊标签

技能使用五种规范分诊角色。本文件将其映射为本仓库使用的标签字符串。

| 角色 | 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此问题 |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可由自主智能体处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提及某个角色时，使用本表中对应的标签字符串。
