## ADDED Requirements

### Requirement: 配债登记日收益事实

服务 MUST 在待配债候选标的可用时返回真实股权登记日收盘价与登记日后第一个交易日收盘价。

#### Scenario: 登记日和后续交易日均有收盘价

- **假定**：候选标的有股权登记日、每股配售额和正股日 K 线。
- **当**：服务构建待配债候选标的响应。
- **则**：`registration_close_price` 等于股权登记日对应交易日的正股收盘价。
- **并且**：`post_registration_close_price` 等于股权登记日之后第一个可验证交易日的正股收盘价。
- **并且**：服务不得使用正股当前价填充 `registration_close_price` 或 `post_registration_close_price`。

#### Scenario: 缺少可验证历史价格

- **假定**：股权登记日或后续交易日没有可验证日 K 线。
- **当**：服务返回候选标的。
- **则**：相关历史价格和收益字段为 `null`。
- **并且**：不得使用当前正股价替代历史收盘价。

### Requirement: 今年上市新债表现

服务 MUST 提供今年上市新债列表，使用中国时区当前自然年筛选上市日，并返回上市以来涨幅、发行规模（剩余规模口径）与东财换手率。

#### Scenario: 今年上市新债有完整行情

- **假定**：某可转债上市日在当前自然年内，且日 K 线与东财行情可用。
- **当**：客户端请求今年上市新债表现。
- **则**：服务返回该标的的上市以来涨幅、`issue_size` 和 `turnover_rate`。
- **并且**：`issue_size` 等于东方财富发行规模（亿元）。
- **并且**：`turnover_rate` 等于东方财富行情换手率（%）。

#### Scenario: 缺少行情事实

- **假定**：某可转债发行规模或换手率缺失。
- **当**：客户端请求今年上市新债表现。
- **则**：对应字段返回 `null`。
- **并且**：不得用推断值或零值伪装。
