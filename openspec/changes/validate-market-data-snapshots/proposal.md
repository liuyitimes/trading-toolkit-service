## 背景与目标

本地持久化快照曾将无法匹配转股数据的新浪可转债行情作为成功结果保存，导致服务重启后仍可能向用户返回缺少正股、转股价和转股价值的条目。本变更确保可转债列表和其可恢复快照只包含可验证的完整记录。

## 范围与非目标

- 在服务端过滤关键转股字段不完整的可转债列表条目。
- 阻止不完整或空的可转债分页结果覆盖已有的持久化快照。
- 不改变可转债 API 路径、响应信封或 LOF 的净值日期语义。
- 不尝试从缺失上游字段推断转股数据。

## 影响

影响可转债数据组装和缓存快照写入。配套 Web 变更为 `trading-toolkit-web/validate-market-data-snapshots`；HTTP 契约保持不变。
