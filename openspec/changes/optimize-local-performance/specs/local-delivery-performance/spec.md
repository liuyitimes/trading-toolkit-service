## ADDED Requirements

### Requirement: 常规读取不等待上游

服务 MUST（必须）使常规读取接口在本地缓存或上次成功快照可用时于一秒内响应，并在后台单飞刷新上游数据。`refresh=true` 可以同步回源，且响应必须保留刷新语义。

#### Scenario: 服务重启后读取列表

- **GIVEN** 服务具有上次成功快照但内存缓存为空
- **WHEN** 用户请求市场或列表端点
- **THEN** 服务在一秒内返回快照
- **AND** 后台最多启动一个该键的刷新任务

### Requirement: 快照状态可观察

服务 MUST（必须）将上次成功快照标识为陈旧数据，且上游不可用时不得将空数据伪装为当前市场事实。

#### Scenario: 没有快照的冷启动

- **WHEN** 常规读取没有本地缓存或快照
- **THEN** 服务立即返回明确不可用响应
- **AND** 启动后台刷新以供后续请求使用
