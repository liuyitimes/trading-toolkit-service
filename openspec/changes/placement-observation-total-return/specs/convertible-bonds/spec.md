## ADDED Requirements

### Requirement: 配债观察范围与状态

服务 MUST（必须）返回尚未上市且已达到 `上市委通过`、`同意注册` 或后续登记、申购、待上市阶段的配债观察标的，并使用明确状态区分当前可参与、登记日未知和已过期。

#### Scenario: 登记日已过的末段标的

- **GIVEN** 未上市标的已在末段审批或后续发行阶段
- **AND** 股权登记日早于当前日期
- **WHEN** 用户读取待配售接口
- **THEN** 响应保留该标的并标记为 `expired`
- **AND** 不将其描述为当前可参与机会

#### Scenario: 早期审批标的

- **GIVEN** 未上市标的尚未达到上市委通过阶段
- **WHEN** 用户读取待配售接口
- **THEN** 响应不将其作为配债观察标的发布
