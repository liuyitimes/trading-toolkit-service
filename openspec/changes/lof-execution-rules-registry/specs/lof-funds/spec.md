## ADDED Requirements

### Requirement: LOF 场内规则接口契约
LOF 列表和详情接口 MUST 在 `execution` 中返回当前有效的场内申购确认时效、场内赎回到账时效和最低申/赎及其字段级证据状态。静态规则与当日开闭状态 MUST 独立表达。

#### Scenario: 静态规则存在但当日状态未核验
- **GIVEN** 某基金存在当前有效的 T+n 或最低申/赎规则，但当天没有开闭状态证据
- **WHEN** 用户请求列表或详情
- **THEN** 接口返回已核验的静态规则和待核验状态
- **AND** 不把该基金标记为可执行套利

#### Scenario: 最低申赎使用不同原始单位
- **GIVEN** 申购下限以元披露且赎回下限以份披露
- **WHEN** 接口返回场内规则
- **THEN** 每个字段保留其值、原始单位和可直接显示的文本
- **AND** 不将金额与份额相互换算
