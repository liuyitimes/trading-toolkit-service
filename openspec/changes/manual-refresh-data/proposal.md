# 手动刷新行情数据

## 为什么

Web 用户需要主动请求当前页面数据重新读取。服务端大多数行情端点已经支持 `refresh=true`，但综合市场概览没有将该请求传递给其组成数据端点，导致首页手动刷新仍可能读取缓存。

## 变更内容

- 综合市场概览端点读取 `refresh=true` 查询参数。
- 强制刷新时，综合概览的可转债温度、LOF 概览、市场情绪和资金流向均使用强制读取。
- 保持现有响应信封、限流、缓存写入和错误契约不变。

## 能力

### 新增能力

- 无。该变更补齐现有强制刷新能力在综合端点的行为。

### 修改能力

- `api-contracts`: 综合市场概览支持 `refresh=true` 查询参数。
- `market-data-reliability`: 强制刷新首页组成行情数据时遵循既有缓存和来源语义。

## 影响

- 服务：`cloudrun/app.py` 及 HTTP 契约测试。
- Web 配套变更：`trading-toolkit-web/openspec/changes/manual-refresh-data`。
- 不改变数据库、依赖或数据源封装。

## 回滚

移除综合概览路由对 `refresh` 参数的处理，恢复默认缓存读取即可。
