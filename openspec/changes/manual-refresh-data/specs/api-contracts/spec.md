## MODIFIED Requirements

### Requirement: 要求：版本化响应信封

业务端点 MUST 使用 `/api/v1/` 前缀，并在成功响应中返回包含 `success`、`data` 和 `meta` 的规范化信封。支持强制刷新的读取端点 MUST 接受 `refresh=true` 查询参数，并将强制读取传递到其数据组成流程。

#### 场景：数据请求成功

- **假定**：客户端请求受支持的业务端点。
- **当**：服务取得数据或允许使用的缓存结果。
- **则**：返回 `{ "success": true, "data": ..., "meta": { ... } }`。
- **并且**：`meta` 在可用时传达来源、缓存状态和更新信息。

#### 场景：综合概览强制刷新

- **假定**：客户端请求 `/api/v1/market/overview?refresh=true`。
- **当**：服务生成综合市场概览。
- **则**：可转债温度、LOF 概览、市场情绪和资金流向均按强制刷新语义读取。
- **并且**：响应仍使用规范化成功信封。
