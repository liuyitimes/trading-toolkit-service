# A-Share Strategy Backtester - Implementation Plan

## Overview

Build a complete A-share strategy backtester from scratch as a new Python package at `trading-toolkit/backtest/`. Uses akshare for 1-minute bar data. Supports full A-share trading mechanics: call auction, continuous auction, matching engine, price limits, order limits, and batch orders.

## Package Structure

```
backtest/
├── pyproject.toml
└── backtest/
    ├── __init__.py          # Public API
    ├── models.py            # Order, Trade, Position, Bar, BoardType
    ├── exceptions.py        # Custom exceptions

```

## Core Classes

### models.py

- `BoardType` enum: MAIN(10%), STAR(20%), CHINEXT(20%), ST(5%)
- `OrderSide`: BUY / SELL
- `OrderType`: LIMIT / MARKET
- `OrderStatus`: PENDING / PARTIAL / FILLED / CANCELLED / REJECTED
- `Order` dataclass: id, symbol, side, type, price, quantity, filled_qty, status, timestamp
- `Trade` dataclass: id, order_id, symbol, side, price, quantity, timestamp, commission
- `Position` dataclass: symbol, quantity, avg_cost, unrealized_pnl
- `Bar` dataclass: symbol, open, high, low, close, volume, timestamp
- `get_board_type(code)` → auto-detect from code prefix (688→STAR, 300→CHINEXT)
- `get_price_limit_pct(board_type)` → decimal limit

### session.py

A-share trading day timeline:
- 09:15-09:25: Opening call auction (limit orders only, no cancellation 09:20-09:25)
- 09:25-09:30: No order acceptance
- 09:30-11:30: Continuous auction (morning)
- 11:30-13:00: Lunch break
- 13:00-14:57: Continuous auction (afternoon)
- 14:57-15:00: Closing call auction

Each bar timestamp is mapped to a `TradingPhase` enum value.

### data.py

- `MarketData` class: loads 1-min bars from akshare via `ak.stock_zh_a_hist_min_em(symbol, period="1", adjust="qfq")`
- Cache loaded data in memory (dict keyed by symbol)
- Provide `get_bars(symbol, start, end)` → list[Bar]
- Provide `get_prev_close(symbol, date)` → float (for price limit calc)

### exchange.py (Matching Engine)

- `OrderBook` per symbol: bids (sorted desc by price) and asks (sorted asc by price)
  - Each price level: `deque` for FIFO time priority
  - Methods: `add_order()`, `remove()`, `get_best_bid/ask()`, `match_continuous()`, `match_auction()`
- `Exchange` class:
  - `submit_order(order)` → validates, routes to OrderBook or immediate match
  - `match_auction(orders)` → price-volume optimization: find price maximizing matched volume
  - `match_continuous(bar)` → fill pending limit/market orders against resting book
  - Returns list[Trade]

### broker.py

- Fee calculation (real A-share rules):
  - Commission: 万3 (0.03%), min 5¥, both sides
  - Stamp tax: 千1 (0.1%), sell only
  - Transfer fee: 万0.2 (0.002%), both sides
- Order validation:
  - Quantity must be multiple of 100 (1手)
  - Price within 涨跌停 range (prev_close ± limit_pct)
  - Sufficient cash for BUY, sufficient position for SELL

### portfolio.py

- `Portfolio` class:
  - Track cash, positions dict[symbol, Position], equity curve
  - `execute_trade(trade)` → update cash, position
  - `get_equity()` → total portfolio value
  - `get_position(symbol)` → Position or None
  - Trade history log

### strategy.py

```python
class Strategy(ABC):
    def on_init(self, data: MarketData, portfolio: Portfolio): ...
    def on_bar(self, bar: Bar, portfolio: Portfolio, phase: TradingPhase) -> list[Order]: ...
    def on_trade(self, trade: Trade): ...
    def on_finish(self): ...
```

- `BuyAndHold(Strategy)` example: buy 500 shares on first bar, hold forever

### engine.py

```python
class Backtester:
    def __init__(self, strategy, symbols, start_date, end_date, initial_cash=1_000_000): ...
    def run(self) -> PerformanceReport: ...
```

Loop per day:
1. Load bars for the day
2. Opening auction phase: collect strategy orders, match auction
3. Continuous phases: for each bar, call `strategy.on_bar()`, submit orders, match continuous
4. Closing auction: same as opening
5. End-of-day: snapshot portfolio, record equity

Error collection: orders that fail validation are logged but don't abort the run.

### metrics.py

- `PerformanceReport`:
  - Total return, annualized return
  - Sharpe ratio, Sortino ratio
  - Max drawdown, max drawdown duration
  - Win rate, profit factor
  - Total trades, total commission
  - Equity curve (list of (date, equity) tuples)

## A-Share Specific Rules Enforced

1. **Lot size**: Orders must be in multiples of 100 shares
2. **Price limits**: Orders rejected if price exceeds prev_close × (1 ± limit_pct)
3. **Call auction**: Only limit orders accepted; matching at single price maximizing volume
4. **T+1**: Sell only shares bought on previous days (position tracking by date)
5. **Fees**: Commission (min 5¥), stamp tax (sell only), transfer fee

## Verification

1. **Unit test**: Create a simple test with known bar data, verify matching produces expected trades
2. **BuyAndHold run**: Run against a real stock (e.g., 000001.SZ) for 1 month, verify equity curve makes sense
3. **Price limit test**: Try submitting order above limit-up price, verify rejection
4. **Call auction test**: Verify opening auction matching produces a single clearing price
5. **Batch order test**: Submit multiple orders atomically, verify all-or-nothing behavior
