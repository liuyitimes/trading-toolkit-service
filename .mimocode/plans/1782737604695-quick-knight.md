# 旺财百宝箱 - 首页重构计划

## 一、目标

将首页从行情数据展示改为**金融工具集合首页**，提供5-8个纯前端计算工具，帮助通过微信审核。

## 二、重构范围

- **仅首页重构**：`miniprogram/pages/index/`
- 其他Tab页面（可转债、LOF、港股、设置）保留不变
- TabBar结构保持5个Tab

## 三、工具选择（8个核心工具）

### 工具1：收益率计算器
- **功能**：计算投资收益率、年化收益率
- **输入**：本金、收益金额、投资天数/月数
- **输出**：总收益率、年化收益率
- **分类**：投资类

### 工具2：复利计算器
- **功能**：计算复利投资收益
- **输入**：本金、年利率、投资年限、复利频率（年/半年/季/月/日）
- **输出**：最终金额、总收益、收益倍数
- **分类**：投资类

### 工具3：定投计算器
- **功能**：计算基金/股票定投收益
- **输入**：每月定投金额、定投年限、预期年化收益率
- **输出**：总投入、最终价值、总收益、收益率
- **分类**：投资类

### 工具4：可转债计算器
- **功能**：计算可转债相关指标
- **输入**：转债价格、转股价、正股价
- **输出**：双低值、转股溢价率、转股价值
- **与现有业务强相关**：复用现有计算逻辑
- **分类**：投资类

### 工具5：LOF套利计算器
- **功能**：计算LOF基金套利收益
- **输入**：基金净值、场内价格、申购费率、投资金额
- **输出**：溢价率、净溢价、套利收益
- **与现有业务强相关**：复用现有计算逻辑
- **分类**：投资类

### 工具6：港股打新收益计算器
- **功能**：计算港股IPO打新收益
- **输入**：发行价、暗盘/首日价格、中签股数
- **输出**：收益率、收益金额
- **与现有业务强相关**：复用现有计算逻辑
- **分类**：投资类

### 工具7：房贷计算器
- **功能**：计算房贷月供和利息
- **输入**：贷款金额、贷款年限、利率、还款方式（等额本息/等额本金）
- **输出**：月供、总利息、还款总额
- **分类**：贷款类

### 工具8：个税计算器
- **功能**：计算个人所得税和税后收入
- **输入**：月薪、五险一金、专项附加扣除
- **输出**：应纳税额、税率、税后月薪、税后年薪
- **分类**：通用类

## 六、实现步骤

### Phase 1：准备工作
1. 创建工具目录结构
2. 创建计算工具模块 (`utils/calculators/`)
3. 注册新的页面路由到 `app.json`

### Phase 2：首页重构
1. 重写 `pages/index/index.wxml` - 工具卡片网格布局
2. 重写 `pages/index/index.wxss` - 卡片样式
3. 重写 `pages/index/index.js` - 工具列表数据、导航逻辑
4. 保留名言轮播功能

### Phase 3：工具页面实现
依次实现8个工具页面：
1. 收益率计算器页面
2. 复利计算器页面
3. 定投计算器页面
4. 可转债计算器页面（复用现有逻辑）
5. LOF套利计算器页面（复用现有逻辑）
6. 港股打新收益计算器页面（复用现有逻辑）
7. 房贷计算器页面
8. 个税计算器页面

### Phase 4：样式统一
1. 设计统一的工具页面模板
2. 实现响应式布局（适配不同屏幕）
3. 支持明暗主题切换

### Phase 5：测试与优化
1. 测试所有计算逻辑的正确性
2. 测试页面跳转和导航
3. 优化用户体验（输入校验、结果展示）
4. 准备微信审核材料

## 七、关键文件

## 八、微信审核要点

1. **纯前端计算**：所有计算在本地完成，无需后端API调用
2. **无实时行情**：不展示实时股票/基金行情数据
3. **工具定位**：明确标注为"金融计算工具"，而非"投资推荐"
4. **免责声明**：在工具页面添加"仅供参考，不构成投资建议"声明
5. **类目选择**：选择"工具"类目，而非"金融"类目

## 九、验证方式

1. 本地测试所有计算工具的正确性
2. 检查页面跳转是否正常
3. 测试明暗主题切换
4. 验证不涉及任何API调用（纯前端计算）
5. 检查是否符合微信小程序审核规范
